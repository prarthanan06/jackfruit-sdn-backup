# SDN Socket Programming - Distributed Backup System (Jackfruit Mini Project)

TCP-based distributed backup system with SDN-controlled path selection, built on Mininet and Ryu.

## Structure
- topology/   Mininet topology scripts
- controller/ Ryu SDN controller
- app/        Client and server (TCP sockets)
- tests/      Test scripts
- docs/       Architecture, setup notes, screenshots
